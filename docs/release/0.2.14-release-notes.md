# 0.2.14 (104) 릴리즈 노트

안드로이드 사용성과 "다른 사람" 콘텐츠가 안 보이던 문제를 고친 릴리즈.
업로드: `python3 scripts/push_release_notes.py`

카피 방향: 첫 두 줄은 인사말 겸 이번 버전의 한 줄 요약. 그 뒤에 유저가 체감하는 변화만 불릿으로.

담긴 것: 다른 사람 메모와 책 새로고침(#70) / 물음 메모 키보드(#73) / 하단 버튼 여백(#76) /
온보딩 사진 건너뛰기(#71) / 책 상세 스낵바 위치(#72) / 표지 없는 책 제목(#75).
서버만 바뀐 것: 다른 사람이 담은 책 최근순(#69, 앱 배포 없이 이미 반영).

## 한국어 (ko)

```
다른 사람들이 남긴 생각이 늦게 도착하고 있었어요.
이제 바로바로 보여요 :)

- 앱으로 돌아오거나 홈을 당기면 다른 사람이 새로 남긴 메모와 담은 책이 보여요
- 안드로이드에서 물음에 메모를 쓸 때 키보드가 입력창을 가리던 문제를 고쳤어요
- 안드로이드에서 화면 아래 버튼이 가려지던 문제를 고쳤어요
- 처음 시작할 때 프로필 사진은 나중에 정해도 돼요
- 표지가 없는 책도 제목으로 알아볼 수 있어요
- 책 화면의 안내 메시지가 제자리에 떠요
```

## English (en)

```
Thoughts from other readers were arriving late.
Now they show up right away :)

- Come back to the app or pull down on Home to see new memos and books from other readers
- Fixed the keyboard covering the text field when writing a memo on Android
- Fixed buttons at the bottom of the screen being hidden on Android
- You can set your profile photo later when you first sign up
- Books without a cover now show their title
- Notices on the book screen now appear in the right place
```
