# 0.2.17 (108) 릴리즈 노트

서버가 잠깐 거절하거나 네트워크가 흔들려도 화면이 튕기거나 로그아웃되거나 저장된 척하지 않게 한 릴리즈 (#95 #96 #97).
2026-11-01 메모 상세 홈 튕김의 근본 수정: 앱의 모든 엣지 함수 호출이 한 관문을 지나며 같은 요청 합치기, 함수별 1초 8번 제한, 일시 오류 재시도를 한다.
iOS 는 0.2.15 와 0.2.16 이 심사 중에 회수돼 그 내용도 처음 나간다. 그래서 App Store 노트 (아래 4개 언어) 는 0.2.15 내용을 합쳤다.
Play 는 0.2.16 이 이미 나가 있어 맨 아래 "Play 용" 블록을 쓴다.
업로드: `python3 scripts/push_release_notes.py`

## 한국어 (ko)

```
알림이 제때, 원하는 만큼만 오도록 다듬었어요.
이제 프로필에서 받고 싶은 알림을 고를 수 있어요 :)

- 내 메모에 댓글이 달리면 바로 알려줘요. 누르면 그 메모로 가요
- 내가 담은 책에 다른 사람 메모가 쌓이면 알려줘요
- 밤 10시부터 아침 7시까지 온 알림은 아침에 모아서 보내요
- 메모 탭에서 새 댓글이 달린 메모를 바로 알아볼 수 있어요
- 댓글을 쓰려고 할 때 홈으로 돌아가 버리던 문제를 고쳤어요
- 연결이 불안정해도 화면이 닫히거나 로그아웃되지 않고 다시 시도할 수 있어요
- 댓글이나 메모를 쓸 때 키보드가 입력 내용을 가리지 않아요
- 메모 탭의 빨간 점이 사라지지 않던 문제를 고쳤어요
```
