# 0.2.15 (106) 릴리즈 노트

알림을 제때, 원하는 만큼만 받게 다듬은 릴리즈.
업로드: `python3 scripts/push_release_notes.py`

담긴 것: 푸시 토큰 저장(#80) / 꺼진 앱 알림 이동(#81) / 꺼진 토큰 정리(#82, 서버) /
알림 서버와 책 메모 마일스톤(#83, 서버) / 알림 설정 화면(#84) / 작성 시각 UTC(#85) /
카드 새 댓글 표시(#86) / 키보드 입력(#87) / 책 메모 알림 이동(#88) / 안드로이드 아이콘(#79).
서버 적용 끝 (2026-11-01): 마이그레이션 2개, 함수 3개 배포, 아침 발송 스케줄.

## 한국어 (ko)

```
알림이 제때, 원하는 만큼만 오도록 다듬었어요.
이제 프로필에서 받고 싶은 알림을 고를 수 있어요 :)

- 내 메모에 댓글이 달리면 바로 알려줘요. 누르면 그 메모로 가요
- 내가 담은 책에 다른 사람 메모가 쌓이면 알려줘요
- 밤 10시부터 아침 7시까지 온 알림은 아침에 모아서 보내요
- 메모 탭에서 새 댓글이 달린 메모를 바로 알아볼 수 있어요
- 댓글이나 메모를 쓸 때 키보드가 입력 내용을 가리지 않아요
- 메모 탭의 빨간 점이 사라지지 않던 문제를 고쳤어요
- 안드로이드 앱 아이콘이 크게 보이던 문제를 고쳤어요
```
