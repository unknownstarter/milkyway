# 0.2.12 (101) 릴리즈 노트

검색이 생긴 릴리즈. 이 앱에 내 메모를 찾는 기능이 처음 들어간다.
업로드: `python3 scripts/push_release_notes.py`

카피 방향: 첫 두 줄은 인사말 겸 이번 버전의 한 줄 요약(제품 서사와 연결).
그 뒤에 유저가 체감하는 변화만 불릿으로. 용량/내부 개선은 쓰지 않는다.

담긴 것: 키워드 검색(#55) / 의미 검색(#63 #64) / 책 제목/저자 검색(#66) /
검색어 강조(#67) / 스낵바가 버튼 덮던 것(#62).

## 한국어 (ko)

```
쌓아둔 메모를 다시 찾을 방법이 없었어요.
이제 찾아집니다 :)

- 단어로 내 메모를 찾을 수 있어요
- 책 제목이나 저자로도 찾아져요. 무슨 낱말로 썼는지 기억 안 나도 괜찮아요
- 단어가 안 겹쳐도 뜻이 가까우면 찾아줘요. '결핍'으로 찾으면 '없음에서 오는 불안'이 나와요
- 어디가 걸려서 나온 결과인지 표시해줘요
- 책을 등록할 때 뜨는 안내가 메모하기 버튼을 가리던 문제를 고쳤어요
```

## English (en)

```
There was no way to find the memos you had piled up.
Now there is :)

- Find your memos by word
- Search by book title or author too, for when the exact wording escapes you
- Even when no words overlap, close meanings surface. Search "lack" and "the unease of not having" comes up
- Results show you what matched
- Fixed the notice covering the write button when you add a book
```

## 日本語 (ja)

```

これからは探せます :)

- 言葉で自分のメモを探せます
- 本のタイトルや著者でも探せます。どんな言葉で書いたか思い出せなくても大丈夫です
- 言葉が重ならなくても、意味が近ければ見つかります
- どこが引っかかって出てきた結果なのかを示します
- 本を登録するときの案内がメモボタンを隠していた問題を直しました
```

## 中文 (zh)
