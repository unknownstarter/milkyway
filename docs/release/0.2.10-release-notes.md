# 0.2.10 (99) 릴리즈 노트

공유 링크 전면 수정 + 앱 용량 다이어트.
App Store Connect / Play Console에 **언어별로 각각** 붙여넣는다.
업로드: `python3 scripts/push_release_notes.py`

## 한국어 (ko)

```
- 공유 링크를 보내면 미리보기 카드가 떠요. 내 단계와 기록이 한눈에 보여요
- 링크를 눌렀을 때 하얀 화면 대신 우주가 그대로 열려요
- 앱 용량을 8MB 넘게 줄였어요. 내려받기가 빨라져요
```
