# 0.2.10 (99) 릴리즈 노트

공유 경험 전면 수정.
업로드: `python3 scripts/push_release_notes.py`

카피 방향: 첫 두 줄은 인사말 겸 이번 버전의 한 줄 요약(제품 서사와 연결).
그 뒤에 유저가 체감하는 변화만 불릿으로. 용량/내부 개선은 쓰지 않는다.

## 한국어 (ko)

```
책 읽다 멈춘 순간이 모인 내 우주,
이제 친구에게 제대로 보여줄 수 있어요 :)

- 공유 링크를 보내면 지금 내 단계와 기록이 담긴 카드가 함께 떠요
- 링크를 열면 별과 오브가 있는 화면이 그대로 보여요
- 앱이 없는 친구도 링크만으로 볼 수 있어요
```

## English (en)

```
The universe you built from the moments you paused,
now it shows up properly when you share it :)

- A shared link comes with a card showing your stage and your record
- Opening the link brings up the same starry screen you see in the app
- Friends without the app can see it from the link alone
```
