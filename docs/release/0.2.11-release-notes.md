# 0.2.11 (100) 릴리즈 노트

공유 링크에 '그때 -> 지금'을 싣는 릴리즈.
업로드: `python3 scripts/push_release_notes.py`

카피 방향: 첫 두 줄은 인사말 겸 이번 버전의 한 줄 요약(제품 서사와 연결).
그 뒤에 유저가 체감하는 변화만 불릿으로. 용량/내부 개선은 쓰지 않는다.

## 한국어 (ko)

```
공유 링크에는 오브 하나만 담겨 있었죠.
이제 멈췄던 순간이 같이 갑니다 :)

- 그때 쓴 문장과 지금 쓴 문장이 링크에 함께 담겨요
- 링크를 받은 사람도 어떤 단계의 우주인지 알 수 있어요
- 책 상세에서 메모하기 버튼이 글을 가리던 문제를 고쳤어요
```

## English (en)

```
A shared link used to be just an orb.
Now the moment you paused travels with it :)

- The line you wrote back then and the one you wrote now go together in the link
- Whoever opens it can see which stage your universe is at
- Fixed the write button covering text on the book page
```
