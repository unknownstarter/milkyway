# 앱 소개 (Description)

버전마다 필수는 아니다(이전 버전 것이 승계된다). 바꿀 때는 **4개 로케일 각각** 고쳐야 한다.

원문에서 고친 것:
- `곳이이에요` 오타
- `당신의 우주가 열어보세요!` - 영구금지인 "당신" 호칭 + 느낌표. `나만의 우주를 열어보세요`로
- 불릿 1~3에 소제목/설명 구분자 ` - ` 추가(4번 불릿과 형태 통일)
- 헤드라인 끝 마침표 제거(짧은 문구 규칙)

## 한국어 (ko)

```
milkyway, 책을 멈춘 순간, 하나의 우주가 열리는 곳

책을 읽다 문득 멈추게 되는 문장이 있죠.
밀키웨이는 그 순간의 생각과 여운을 담는 곳이에요.

한 권의 책, 한 줄의 메모가 모여 나만의 우주가 되고
같은 책에 멈춘 다른 사람들의 우주와 만나 생각이 이어져요 :)

- 멈춘 순간을 메모로 - 밑줄 대신 마음을 기록해요
- 물음이 건네는 깊이 - 내 문장에 물음이 더해져 생각이 더 멀리 가요
- 다른 우주와 만남 - 같은 책을 읽은 사람들의 생각을 만나고 나눠요
- 쌓이는 나의 기록 - 담은 책, 메모, 읽은 날들이 하나의 궤적이 돼요

책을 읽다 멈춘 곳에서, 나만의 우주를 열어보세요
```
