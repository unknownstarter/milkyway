# 밀키웨이 타이포그래피 정본 — Pretendard 단일 + 자간·행간

> **작성일**: 2026-08-15
> **상위**: `01-DESIGN_PHILOSOPHY.md` (원칙 4 하나의 문법 · 원칙 6 쉬운 말)
> **결정(노아)**: 폰트는 **무조건 Pretendard 하나로 통일.** 명조(Noto Serif) 등 세리프 혼용 폐기 — 프리뷰에서 "문장=명조" 실험은 취소. 도구도 콘텐츠도 전부 Pretendard.

---

## 1. 폰트 — Pretendard 단일

- **fontFamily = `Pretendard`** (fallback: `-apple-system, 'Apple SD Gothic Neo', sans-serif`).
- 세리프/타 폰트 혼용 금지. 위계는 **크기·굵기·자간·행간**으로만 만든다(폰트 종류로 만들지 않는다). → 원칙 4(하나의 문법).
- 웹 프리뷰는 Pretendard CDN, 앱은 번들된 Pretendard.

## 2. 자간(letter-spacing) — 한글 가독 원칙

한글은 라틴보다 글자 밀도가 높아, **큰 글자일수록 자간을 살짝 좁히면(negative)** 덩어리감이 좋아지고, **본문은 0에 가깝게** 둔다. (Toss·Pretendard 생태계 관용값과 정합.)

| 역할 | 크기 | 자간(em) | 자간(px, 실측 반올림) |
|------|------|----------|------------------------|
| display | 28 | -0.03em | **-0.8** |
| heading | 24 | -0.025em | **-0.6** |
| title | 20 | -0.02em | **-0.4** |
| subtitle | 18 | -0.02em | **-0.35** |
| body / bodyBold | 16 | -0.01em | **-0.2** |
| bodySmall | 14 | -0.01em | **-0.15** |
| caption | 12 | 0 | **0** |
| label | 12 | 0 | **0** |

> 원칙: 제목 -0.02~-0.03em, 본문 -0.01em, 캡션 0. 그 이상 좁히면 답답, 양수 자간은 한글에서 성글어 보이므로 쓰지 않는다.

## 3. 행간(line-height) — 읽기 좋은 값

한글 본문은 받침 때문에 라틴보다 **넉넉한 행간(1.5~1.7)**이 읽기 좋다. 제목은 조여서 덩어리로 읽히게.

| 역할 | line-height | 근거 |
|------|-------------|------|
| display 28 | **1.25** | 큰 제목은 조여 덩어리감 |
| heading 24 | **1.3** | |
| title 20 | **1.35** | |
| subtitle 18 | **1.4** | |
| **body 16 (본문·메모)** | **1.6** | 읽는 텍스트 = 가장 넉넉히. 메모 본문이 핵심 |
| bodySmall 14 | **1.55** | |
| caption 12 | **1.4** | 짧은 메타 |
| label 12 | **1.3** | 배지·태그 |

## 4. 스케일 (크기/굵기/자간/행간 종합)

| 토큰 | size / weight | letter-spacing | line-height | 쓰임 |
|------|---------------|----------------|-------------|------|
| `display` | 28 / Bold | -0.8 | 1.25 | 최상위 화면 타이틀 |
| `heading` | 24 / w600 | -0.6 | 1.3 | 화면 메인 헤더 |
| `title` | 20 / w600 | -0.4 | 1.35 | 섹션 헤딩("내 메모") |
| `subtitle` | 18 / w600 | -0.35 | 1.4 | 카드 강조·다이얼로그 제목 |
| `body` | 16 / w400 | -0.2 | 1.6 | 본문·메모(기본) |
| `bodyBold` | 16 / w600 | -0.2 | 1.6 | 본문 강조·버튼 라벨 |
| `bodySmall` | 14 / w400 | -0.15 | 1.55 | 보조 설명 |
| `caption` | 12 / w400 | 0 | 1.4 | 캡션·메타(시간·페이지) |
| `label` | 12 / w600 | 0 | 1.3 | 배지·태그 |

> 색은 기본 `AppColors.textPrimary`, 필요 시 `.copyWith(color:)`. 정본 코드: `lib/core/theme/app_typography.dart`.

## 5. 적용 규칙 (원칙 4)

- 신규·수정 코드는 **인라인 `TextStyle` 대신 `AppTypography.*`** 사용. 인라인 `fontSize`/`fontWeight` 재발명 금지.
- 기존 배포 화면의 인라인 스타일은 손대는 김에 토큰으로 치환(비파괴적, 점진 적용).
- **적용 태스크는 실행계획 참조**: `docs/handoff/2026-08-15-ACTION-PLAN.md` (워크스트림 A).
